Gallery 5 · Words, words, words

The Verbose Hall

Other languages use symbols. COBOL uses verbs. The code reads like instructions to a very literal office clerk, which is exactly what a computer is.

The Most Famous Joke

Origin unknown · still funny

ADD 1 TO COBOL GIVING COBOL

In C, C++ means "add one to C", which is how C++ got its name. This is the COBOL version of the same joke. It is longer. Of course it is longer.

Tell me more

It's also valid COBOL, as long as you declare a numeric field named COBOL. That name isn't a reserved word, so the compiler won't stop you. Your colleagues might.

The display cases

Each case shows a COBOL verb next to how a modern language (here, Python) would say it.

MOVE · copy a value

COBOLPython
MOVE "Grace" TO WS-FIRST-NAMEfirst_name = "Grace"
MOVE ZERO TO WS-TOTALtotal = 0

Note the direction: COBOL reads left to right, like a sentence. And MOVE quietly pads or cuts the value to fit the PIC of the field it lands in.

ADD · SUBTRACT · MULTIPLY · DIVIDE

COBOLPython
ADD WS-TAX TO WS-PRICE GIVING WS-TOTALtotal = price + tax
SUBTRACT WS-FEE FROM WS-BALANCEbalance -= fee
MULTIPLY WS-HOURS BY WS-RATE GIVING WS-PAY ROUNDEDpay = round(hours * rate, 2)
DIVIDE WS-TOTAL BY 12 GIVING WS-MONTHLYmonthly = total / 12

Add ON SIZE ERROR to any of them and COBOL will tell you when a result is too big for its field, instead of quietly chopping off digits.

COMPUTE · for when you want a formula after all

COBOLPython
COMPUTE WS-PAY = WS-HOURS * WS-RATE * 1.5pay = hours * rate * 1.5

Added because even COBOL's designers eventually wanted a *.

IF · EVALUATE · making decisions

COBOLPython
IF WS-BALANCE < 0 DISPLAY "OVERDRAWN" END-IFif balance < 0: print("OVERDRAWN")
EVALUATE TRUE
  WHEN WS-ACTIVE ...
  WHEN OTHER ...
END-EVALUATE		match True:
  case _ if active: ...
  case _: ...

EVALUATE is COBOL's switch statement, and it's a good one. This repo's library uses EVALUATE TRUE to choose which function to run.
