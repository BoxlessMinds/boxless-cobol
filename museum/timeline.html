Gallery 8 · Sixty-plus years in one hallway

The Timeline Corridor

Walk the corridor from 1960 to today. Solid frames are COBOL standards. Dashed frames are the machines and tools around it. Scroll sideways (or down, on a phone).

1960
COBOL-60

What changed: everything. The first specification is published.

Fun detail: by December it runs on two different makers' machines.

1961
COBOL-61

What changed: the first revision, cleaning up problems found by real users.

Fun detail: an "Extended" edition soon adds SORT and the Report Writer.

1964
Machines

IBM System/360 arrives. One family of compatible mainframes, and COBOL becomes a standard tool on them.

Fun detail: its descendants still run COBOL today.

1965
COBOL-65

What changed: better tables and support for mass-storage files.

Fun detail: "mass storage" meant disks the size of washing machines.

1968
ANSI COBOL 68

What changed: the first official ANSI standard (X3.23-1968).

Fun detail: the US government soon requires its computers to support it.

1970s
Machines

Terminals with green screens start replacing punch cards for typing code.

Fun detail: the 80-column layout comes along anyway.

1974
ANSI COBOL 74

What changed: file handling grows up, with indexed and relative files.

Fun detail: much of the COBOL still running today was written to this standard.

1985
COBOL-85

What changed: structured programming. END-IF, EVALUATE, inline PERFORM.

Fun detail: fewer periods needed. Dot took it personally.

1980s
Machines

PC compilers let people write COBOL on a desk instead of in a machine room.

Fun detail: the mainframe was still waiting at the other end.

1999
Event

Y2K. The biggest code review in history.

Fun detail: see Gallery 7. Bring coffee.

2002
ISO COBOL 2002

What changed: object-oriented COBOL, free-format source and user-defined functions.

Fun detail: yes, COBOL has classes. Few people use them.

2000s
Tools

OpenCOBOL, later renamed GnuCOBOL: a free compiler that turns COBOL into C. This repo uses it.

Fun detail: it runs on a laptop, a Raspberry Pi or WSL.

2014
ISO COBOL 2014

What changed: a tidy-up. Some rarely used features become optional, and modern floating-point arrives.

Fun detail: the standard keeps getting edited, which is more than most 1959 documents can say.

2020s
Tools

VS Code extensions, free online courses and open-source mainframe tools.

Fun detail: COBOL now has syntax highlighting in dark mode.

2023
ISO/IEC 1989:2023

What changed: the current standard, with more modern features.

Fun detail: COBOL turned 64 that year and was still getting new features.
