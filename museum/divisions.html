The Four Divisions Wing

A COBOL program is a building with four rooms, always in the same order. You always know where to look: who the program is, what machine and files it uses, what data it holds, and what it does.

IDENTIFICATION ENVIRONMENT DATA PROCEDURE

IDENTIFICATION DIVISION

Required · "Hello, my name is..."

The reception desk. It gives the program its name with PROGRAM-ID. That name is how other programs CALL it. In this repo's library, the PROGRAM-ID must match the file name.

----+----1----+----2----+----3       IDENTIFICATION DIVISION.
       PROGRAM-ID. HELLO.

ENVIRONMENT DIVISION

Optional · The machine room

Everything that depends on the outside world lives here, mainly the files. FILE-CONTROL connects the name the program uses to a real file on disk. If you move to a new computer, this is the room you redecorate. The rest of the building can stay the same.

----+----1----+----2----+----3----+----4       ENVIRONMENT DIVISION.
       INPUT-OUTPUT SECTION.
       FILE-CONTROL.
           SELECT EMP-FILE ASSIGN TO "employees.dat".

DATA DIVISION

Optional (but nearly always there) · The library

Every variable is declared here before any code runs. Each one gets a level number (where it sits in the box) and a PIC clause (its exact size and type). There's no "let x = 5" anywhere else. The next gallery is all about PIC.

Touch screen: The Level Numbers Russian Doll

Open the boxes · from lesson 02

A group item is a box that holds smaller items. An elementary item has a PIC clause and holds the actual data. Bigger level numbers sit inside smaller ones. Click to open.

01 WS-CUSTOMER (group: 35 bytes)

The whole customer record. It has no PIC of its own; it's just the sum of its parts, in order.

05 WS-CUST-ID   PIC 9(5)   VALUE 42 → "00042"
05 WS-CUST-NAME (group: 20 bytes)

A box inside the box.

10 WS-FIRST-NAME   PIC X(10) → "Grace     "
10 WS-LAST-NAME   PIC X(10) → "Hopper    "
05 WS-BALANCE   PIC S9(7)V99 → -1234.50 (9 bytes, no "." stored)
05 WS-STATUS   PIC X   VALUE "A"

88-levels aren't boxes. They're names for values this field can hold, and they read like true/false.

88 WS-ACTIVE   VALUE "A" → true right now

PROCEDURE DIVISION

Optional · The factory floor

Where the work happens. Code is organized into paragraphs (named blocks, in Area A) made of sentences (ending in a period) made of statements (verbs like MOVE and ADD). Yes, it's grammar class. That was on purpose.

----+----1----+----2----+----3----+----4       PROCEDURE DIVISION.
       MAIN-PARA.
           DISPLAY "Hello from COBOL"
           STOP RUN.

Dot says: See me at the end of every division header? I close the door behind you. Forget me and the compiler wanders into the next room confused.
