Free download: the COBOL cheat sheet

One page, printable. Press the button and choose "Save as PDF" if you want a file.

The four divisions

  • IDENTIFICATION: the name (PROGRAM-ID)
  • ENVIRONMENT: files and machine setup
  • DATA: every variable, declared up front
  • PROCEDURE: the code that runs

The columns

  • 1–6: sequence number (ignored)
  • 7: * comment, - continuation
  • 8–11: Area A (divisions, paragraphs, 01)
  • 12–72: Area B (statements)
  • 73+: ignored. Silently.

PIC symbols

  • 9 digit · X any char · A letter
  • V implied point (no byte) · S signed
  • Z zero becomes space · $ , . printed
  • 9(5) = 99999

Top 10 verbs

  • MOVE · ADD · SUBTRACT
  • MULTIPLY · DIVIDE · COMPUTE
  • IF · EVALUATE · PERFORM
  • DISPLAY (and finally STOP RUN)
