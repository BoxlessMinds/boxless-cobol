# The COBOL Museum: Image Prompts

Each image slot on the site shows its prompt ID (for example `IMG-07`) and file name until the image exists. Generate the image from the prompt below, save it under `museum/assets/img/` with the listed file name, and the page picks it up automatically. Then add a row to the Image credits table on `resources.html`.


**House style suffix** (append to every prompt so the set looks consistent):
> *, mid-century modern museum illustration, 1960s corporate poster style, flat
> shapes with subtle paper grain, limited palette of punch-card manila, mainframe
> blue, terminal green and brass, soft directional lighting, no text unless specified,
> no logos or real brand marks*

**Rules for all images:** export WebP, max 1600px wide (hero) or 800px (exhibit); file
names `img-NN-slug.webp` in `museum/assets/img/`. Portraits of real people (Hopper,
Sammet) must be stylized illustrations, not photo-real likenesses; check the image
tool's rules on real people, or use public-domain photos from the US Navy or other
archives instead (credit them on the Resources page).
