The Living Workshop

Enough looking. In this room you write COBOL. Everything here links to a real program in this repo that you can build, run and change.

Exhibit: Your Toolkit

1. Install the compiler

Windows: GnuCOBOL lives inside WSL

This repo compiles with GnuCOBOL (cobc) inside WSL. In PowerShell:

wsl --install
wsl sudo apt update
wsl sudo apt install gnucobol make

On Linux, skip the wsl and run the apt lines directly. On a Mac, brew install gnucobol.

2. Build and run

From the repo root, in PowerShell

.\build.ps1
.\build.ps1 run -Name tutorials\01-hello\hello.cob
.\build.ps1 test

The first line builds everything. The second runs one program. The third runs the library's unit tests. Inside WSL, use make, make run NAME=... and make test.

Exhibit: Read Real Code

This is lesson 01 from the repo, with part of its comment block left out. The green ruler shows the columns. Comment lines have * in column 7, and the code starts at column 8.

----+----1----+----2----+----3----+----4----+----5----+----6----+----7--       IDENTIFICATION DIVISION.
       PROGRAM-ID. HELLO.
      *****************************************************************
      * Lesson 01 - Hello, COBOL
      *
      * Fixed-format source layout (the classic 80-column card):
      *   columns 1-6   sequence number area (ignored)
      *   column  7     indicator: '*' = comment line, '-' = continue
      *   columns 8-11  Area A: division/section/paragraph names, 01s
      *   columns 12-72 Area B: statements
      *****************************************************************
       PROCEDURE DIVISION.
           DISPLAY "Hello from COBOL".
           STOP RUN.

Dot says: Change "Hello from COBOL" to your own name and run it again. Congratulations, you're a COBOL programmer. The banks will be in touch.
